ML: Chess V2 (or ML: Chess 2.0) is a fixed and fully-functioning remake of a high school project with the same goal: Allow users to play chess using voice commands.
Users will press the start button to begin recording their input, and when their input has been picked up, can lock in their choice by pressing the confirm button. User input can range from a specific tile, a type of piece during pawn promotion, or "draw" to request a draw.
I hope you have fun!
